# 🌈 初級學課互動樂園

安息日學「初級學課」互動學習網站（兒童版），把教師版 PDF 內容變成孩子能自己玩的互動樂園。

## 內容
- **21 課**：A年（第2~4季）＋ B年（第1~4季），每季 3 課
- 每課包含：聖經出處、本課信息、兒童故事（4~5段）、存心節、互動問答（2題）、生活回應
- 來源：`~/Desktop/安息日學資源檔/初級學課/` 教師版 PDF（用 MarkItDown 提取）

## 玩法（每課集 3 顆星）
1. ⭐ **故事關**：點「🔊 全部朗讀」聽故事，聽完按「我聽完故事了！」
2. ⭐ **存心節關**：按「🔊 跟我讀」學背，記住後按「我記住存心節了！」
3. ⭐ **問答關**：答對全部問題自動得星

進度自動保存在瀏覽器（localStorage），集滿星星很有成就感！

## 使用
**不用伺服器**，直接雙擊 `index.html` 即可用（手機、平板、電腦都行）。

或本地預覽：
```bash
cd 初級學課互動
node server.js
# 開啟 http://localhost:8777（含 Edge 神經語音 /tts 合成）
```

## 檔案結構
```
初級學課互動/
├── index.html        首頁（選學季、課程卡片、總進度）
├── lesson.html       課程頁（故事/存心節/問答/星星）
├── css/style.css     樣式（兒童友善彩虹風格）
├── js/app.js         邏輯（進度、朗讀、問答）
├── data/lessons.js   21課全部資料（含故事與題目）
└── raw/              教師版 PDF 提取的原始 Markdown
```


## 🔊 Edge 神經語音（曉曉/雲希）
右下角 **🎙️ 語音設置** 可選：曉曉（溫柔女聲）/ 雲希（陽光男聲）/ 曉伊（卡通活潑）/ 自動。

- **本地預覽**：用 `node server.js` 啟動，會自動走 Edge 神經語音伺服器合成（真聲，推薦）。
- **線上（GitHub Pages）**：自動改用瀏覽器語音；用 **Edge 瀏覽器** 開啟時，曉曉/雲希 神經音色可直接用。
